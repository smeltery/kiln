01 / Identity

A solid environment for the work.

Kiln supplies a Wolfi-based environment for GitHub Actions run locally through act. Its identity is solid, prepared, and direct. The chamber symbol connects the physical kiln with the runner environment. Shared typography and neutral colors relate it to Bellows.

  • Keep one quarter of the symbol height clear around the visible lockup.
  • Minimum digital sizes: 16 px symbol height and 160 px lockup width.
  • Use the supplied geometry, orientation, spacing, and color variants.
02 / Color

Fired gold. Solid ground.

Use Paper and Ink for most of the composition. Use Gold for one point of emphasis. Choose Ink text on Gold; use Burnt Gold #7A4D16 for accent text on Paper.
